## About me

I'm a web developer and product-minded builder based in Lagos, Nigeria, preparing for my studies at the University of Lagos. I enjoy working across the full product lifecycle: shaping an idea, designing the experience, building the interface, connecting the backend, and shipping something people can actually use.

My current direction is a mix of **full-stack web development, AI-powered products, frontend engineering, and product design**. I'm also gradually exploring **cybersecurity** while continuing to sharpen my core skills.

> I build seriously, experiment often, and sometimes ship a project just because I was bored — that's how **Awesome Generator** happened. 🙂

## What I'm focused on

- Building scalable, user-friendly full-stack web applications
- Designing clean, responsive interfaces with strong product thinking
- Integrating AI into practical tools and delightful user experiences
- Improving architecture, deployment, and developer workflows
- Learning cybersecurity at a steady pace alongside web engineering
